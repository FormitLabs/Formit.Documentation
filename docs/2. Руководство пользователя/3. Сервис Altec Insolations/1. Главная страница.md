Вы можете перейти в сервис __*AltecInsolations*__ по прямой ссылке или из личного кабинета, вкладка *“Мои продукты”*.

<image image={glImage} width="100%" title="Рисунок 23 - Главная Insolations."/>

*[1] - панель управления (файлы , общий доступ, настройки пользователя, помощь);*  
*[2] - ранее выгруженные модели;*  
*[3] - поиск проектов по названию;*  
*[4] - панель управления проектами (всплывает при нажатии на проект);"*  
*[5] - сортировка по дате выгрузки проекта"*  
*[6] - выбор отображения проектов;*  
*[7] - информация о проекте.*



На главной странице (рис. 23) вы увидите тестовую модель и ранее экспортированные Вами файлы [2]. Если выбрать кнопку последние файлы, появится список проектов в порядке очередности по открытию (от недавно открытых к более давним) [5].

Для навигации можно воспользоваться поиском по названию, выбрать удобный режим отображения: *список или таблица* [6].

 

На значке модели, пользователю показывается превью модели и её вес. 

При нажатии на значок модели появляется панель управления проектами [4]. Пользователь видит действия, которые возможно совершить с загруженной моделью, а именно: скачать, переместить в папку, переименовать, удалить.

При нажатии на значок папки появляется панель управления папками [4]. Можно переместить в папку файлы, переименовать папку, удалить её.

Открыть модель можно дважды нажав на иконку модели левой кнопкой мыши (далее ЛКМ). 
Открывается окно сервиса Altec Insolations.
