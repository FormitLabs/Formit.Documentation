# HTTP Proxy в Revit Exporter

***

## Область действия прокси
На данный момент прокси используется при работе с сервером проектов (загрузка списка проектов, отправка экспортируемого проекта на сервер).

## Настройка прокси
Конфигурация происходит через размещение файла `proxy.json`, по пути: `%AppData%\AltecSystems\Exporter.Revit\proxy.json`. 
Пример содержимого файла настроек (минимальная конфигурация): 
```json
{
  "address": "http://127.0.0.1:8888"
}
``` 
параметр `address` обязательный, шаблон `{http|https}://{ip}:{port}`. 

Поддерживается указание `user` и `password` от прокси сервера.
Пример содержимого файла настроек с данными авторизации: 
```json
{
  "address": "http://127.0.0.1:8888",
  "user": "username",
  "password": "12345"
}
```
