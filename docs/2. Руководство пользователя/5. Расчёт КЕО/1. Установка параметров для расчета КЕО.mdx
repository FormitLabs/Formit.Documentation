## Основные настройки КЕО. Коэффициенты C<sub>N</sub>, MF.

Во вкладке “Настройки” пользователь указывает номер административного района для расчета коэффициента C<sub>N</sub> (его можно определить в документации), в котором находится объект, автоматически устанавливается коэффициент эксплуатации - МF. (при наведении на значок информации (справа от коэффициента), пользователь увидит подсказку, что обозначает данный коэффициент) (<ImageLink to="general-settings"/>).

Вводятся значения MF только для угла наклона светопропускающего материала к горизонту в пределах 76°-90° (Боковое КЕО). 

<Image image={qImage} id="general-settings" width="35%" title="Основные настройки"/>

## Общий коэффициент отражения фасада

Пользователю необходимо поочередно выбрать каждое здание, в дополнительно открывшейся вкладке указать для них ρ<sub>ф</sub> - общий коэффициент отражения фасада (<ImageLink to="rof"/>).

<Image image={eImage} id="rof" width="70%" title={<>Настройка ρ<sub>ф</sub></>}/>

Перед выбором коэффициента, необходимо задать его параметры. При нажатии на строку “Общ коэф отр фасада” появляется выбор “Редактирование”, пользователю необходимо нажатием открыть окно редактирования.


Открывается окно “Список Коэффициентов отражения фасада”. Здесь будут отображаться созданные пользователем варианты фасадов (<ImageLink to="create-rof"/>). При необходимости создания нового, пользователь нажимает на соответствующую кнопку (<ImageLink to="create-rof"/>).

<Image image={rImage} id="create-rof" title={<>Создание нового ρ<sub>ф</sub></>}/>

Далее пользователь выбирает *“Добавить материал фасада”* (<ImageLink to="create-rof-part"/>).


<Image image={tImage} id="create-rof-part" title="Добавить материал фрагмента фасада "/>


В строке, выбираем материал фрагмента фасада, соответствующий материалу затеняющего фасада здания. Также пользователю нужно выбрать коэффициент отражения фасада и ввести весовой коэффициент - площадь данного фрагмента в м. кв. (<ImageLink to="create-and-edit-rof-part"/>).

База материалов заимствована из нормативной документации (СП 52, СП 367). 

<Image image={yImage} id="create-and-edit-rof-part" title="Создание и настройка средневзвешенного коэффициента отражения фасада"/>

После ввода данных пользователь может сохранить созданный элемент фасада или отменить это действие (<ImageLink to="save-rof"/>).
При необходимости, аналогичным образом добавляем дополнительные материалы. Итоговый коэффициент будет рассчитан автоматически.

<Image image={uImage} id="save-rof" title="Сохранение настройки средневзвешенного коэффициента отражения фасада/отмена создания"/>

Нажимаем на кнопку *"Сохранить"* в нижнем правом углу, вычисленный коэффициент сохранится автоматически (<ImageLink to="actually-save-rof"/>).


<Image image={iImage} id="actually-save-rof" title="Сохранение средневзвешенного коэффициента отражения фасада"/>


После сохранения коэффициента можно закрыть окно.
В строке выбора пользователь выбирает созданный средневзвешенный коэффициент отражения фасада (<ImageLink to="select-rof"/>).

<Image image={pImage} id="select-rof" width="45%" title="Выбор значения средневзвешенного коэффициента отражения фасада"/>

## Назначение коэффициентов τ

Ниже, в этом же окне, показан список типов окон, спроектированных в программе Revit, для каждого из них нужно указать значения коэффициентов, которые влияют на уровень пропускания света в различных конструкциях (<ImageLink to="select-tau"/>), все значения можно определить в документации.

Коэффициенты можно вводить сразу для нескольких типов окон с помощью мультиселекта. Чтобы это сделать зажимаем "ctrl", снять выделение с окна можно так же при зажатом "ctrl". Чтобы выделить диапазон, зажимаем "shift".

При выделении, соответствующие типы окон подсвечиваются в сцене.

<Image image={aImage} id="select-tau" width="80%" title="Выбор коэффициентов пропускания света"/>


Коэффициенты τ настраиваются для всех витражей в проекте одновременно (<ImageLink to="select-tau-cw"/>).

<Image image={glaImage} id="select-tau-cw" width="50%" title="Выбор коэффициентов пропускания света для витражей"/>

### Коэффициент τ<sub>1</sub>

τ<sub>1</sub> - остекление. Пользователь выбирает тип остекления (формула окна), для каждого типа окна доступен один или несколько вариантов коэффициента, нужно выбрать его самостоятельно.

Также при отсутствии вашего типа остекления в нормативной базе, можно создать формулу остекления через *"Редактирование"*.

Нажимаем *"Создать формулу остекления"*. (<ImageLink to="window-formula"/>) Активируется строка редактирования.

<Image image={osttImage} id="window-formula" title="Создание формулы окна"/>

Вводим название формулы, при необходимости подгружаем сертификат. Нажимаем на "добавить" и вписываем соответствующие вашему типу остекления показатели. (<ImageLink to="window-formula-2"/>)

<Image image={ostsImage} id="window-formula-2" title="Создание формулы окна"/>

Для сохранения нажимаем зеленую галочку (<ImageLink to="save-window-formula"/>).<br/>
Теперь созданный вами коэффициент можно выбрать в общем выпадающем списке.

<Image image={osImage} id="save-window-formula" title="Сохранение формулы окна"/>

### Коэффициент τ<sub>2</sub>

#### Для окон

τ<sub>2</sub> - переплет. Необходимо создать тип переплета для расчета коэффициента. В строке выбора переплета пользователь нажимает вариант на *"Редактирование"*. Открывается окно редактирования, нажимаем *“Создать тип окна”* (<ImageLink to="create-tau2"/>). Открывается калькулятор расчета коэффициента. Вбиваются габаритные значения в необходимую ячейку, указывается название.
Габариты окон указываются в метрах (<ImageLink to="tau2-calc"/>).

<Image image={sImage} id="create-tau2" title={<>Окно создания коэффициента τ<sub>2</sub></>} />
<Image image={dImage} id="tau2-calc" title={<>Калькулятор создания коэффициента τ<sub>2</sub></>} />

При нажатии клавиши *"Добавить блок"* вы сможете указать габариты балконного проема (<ImageLink to="balcony"/>).

<Image image={slgtImage} id="balcony" title="Настройка габаритов балконного проема"/>

При нажатии клавиши *"Задать значение вручную"* пользователь может ввести значение τ<sub>2</sub> из списка СП 367.1325800.2017 Изм.2 табл. А.19 (<ImageLink to="manual-tau2"/>).

<Image image={vrmImage} id="manual-tau2" title={<>Ручное задание τ<sub>2</sub></>}/>

В правой нижней части окна можно сохранить или отменить создание.

#### Для витражей

τ<sub>2</sub> - при выгрузке модели  сервис  автоматически определяет габариты витража, площадь импостов, поэтому необходимо задать только коэффициент отражения переплёта p. Его значение вводится вручную в зависимости от материала.

<Image image={gla2Image} id="cw-ro" width="50%" title="Коэффициент p для витража"/>

Если не ввести коэффициент *p* и запустить расчет, то на экране появится предупреждение (<ImageLink to="tau2-alert"/>).

<Image image={t2pImage} id="tau2-alert"  width="50%" title="Предупреждение"/>

### Коэффициенты τ<sub>3</sub>, τ<sub>4</sub>, τ<sub>5</sub>

τ<sub>3</sub> - несущие конструкции. При боковом освещении τ<sub>3</sub>=1;  
τ<sub>4</sub> - затеняющие конструкции. Пользователь также указывает, какие конструкции соответствуют выбранному типу окна. По умолчанию коэффициент равен 1;  
τ<sub>5</sub> - наличие или отсутствие защитной сетки. По умолчанию коэффициент равен 1.

Пользователь проделывает эти действия для каждого типа окна, а далее для всех зданий. Мультиселект позволяет задавать τ сразу для нескольких типов окон. На рисунке выделено 3 типа окна. Они подсвечиваются синим цветом.

После того как выставлены все коэффициенты, можно закрыть поле настроек коэффициентов здания с помощью кнопки *"Применить"* (<ImageLink to="apply-coefficients"/>).

<Image image={fImage} id="apply-coefficients" width="70%" title="Применение настроек коэффициентов"/>

### ρ<sub>ср</sub> - средневзвешенный коэффициент отражения внутренних поверхностей помещения; 
По СП 52.13330.2016, п. 5.10 для жилых и общественных зданий расчётное значение коэффициента следует применять 0,55.

Во вкладке *Помещения* пользователь может создать с помощью калькулятора свой коэффициент отражения материала помещения. 

Для создания коэффициента перейдите в *Редактирование*(<ImageLink to="create-ro-avg"/>). Нажмите на кнопку *Создать коэффициент отражения внутренних поверхностей помещения* (<ImageLink to="create-ro-avg-2"/>).

<Image image={pcpImage} id="create-ro-avg" width="50%" title="Создание коэффициента"/>

<Image image={pcp2Image} id="create-ro-avg-2" title="Создание коэффициента" />

Введите площадь, которую данный материал занимает и выберите из списка материал. Если в проекте используется несколько материалов, их также можно указать, нажав кнопку *Добавить*.(<ImageLink to="create-material"/>)

<Image image={sozdpcpImage} id="create-material" title="Добавление материалов"/>

Также пользователь может настроить для каждого помещения свой коэффициент ρ<sub>ср</sub>. В списке выберите помещение и в появившемся сбоку всплывающем окне задайте ρ<sub>ср</sub>. 

<Image image={createRoAverageForRoomsImage} id="ro-avg-for-rooms" width="80%" title={<>Создание ρ<sub>ср</sub> для помещений</>}/>

### Коэффициент К
Сервис автоматически производит расчёт данного коэффициента, значения выводятся в отчёт для каждого помещения. 
Размеры балконов/лоджий «подтягиваются» из квартирографии при экспорте.

## Выбор объектов

Выбор объекта для расчета происходит через дерево объектов. Во вкладке “Дерево объекта” (<ImageLink to="modal-explorer"/>) можно выбрать как все здания, сразу так и отдельный этаж, квартиру или помещение.

<Image image={gImage} id="modal-explorer" width="35%" title="Дерево объектов"/>

## Настройка положения расчетной точки КЕО

Для корректного расчета КЕО необходимо задать каждому помещению свой тип. Настройка типов помещения в сервисе производится автоматически (в соответствии с существующей базой словарей). Также есть возможность создать свои словари с необходимыми параметрами. 

Во вкладке КЕО выбираем здание, в котором находится нужное помещение (<ImageLink to="select-building"/>).

<Image image={tk1Image} id="select-building" width="35%" title="Выбор здания"/>

Переходим во вкладку *Помещения* (<ImageLink to="rooms-tab"/>).

<Image image={tk2Image} id="rooms-tab" width="35%" title="Вкладка помещения"/>

В этом окне отображаются этажи и помещения, относящиеся к ним. 
Помещения в сцене автоматически распределяются на 3 категории (<ImageLink to="room-categories"/>).

<Image image={tkk2Image} id="room-categories" width="35%" title="Категории помещений"/>

![](../../resources/frame/red.png) - **Тип не указан** (например, в автоматическом подборе словаря, определении границ помещения);  
![](../../resources/frame/yell.png) - **Нужно выбрать тип** (например, необходимо произвести выбор между несколькими словарями для указания типа помещения);  
![](../../resources/frame/gre.png) - **Тип указан** .  (тип автоматически определился в соответствии с системным/пользовательским словарем).

При нажатии на категорию можно увидеть все определенные к ней помещения.

Изучить системные словари (созданные в соответствии с действующей нормативной документацией) или создать пользовательские можно через опциональное меню, которое открывается нажатием кнопки *"Словари"* (<ImageLink to="dictionaries"/>).

<Image image={dictionImage} id="dictionaries" width="35%" title='Кнопка "Словари"'/>

В открывшемся окне список системных словарей. (<ImageLink to="system-dictionaries"/>)

<Image image={sisdictImage} id="system-dictionaries" title="Список словарей"/>

Нажимаем на 3 точки. Пользователь может открыть интересующий его системный словарь и изучить его параметры (<ImageLink to="system-modal"/>).

<Image image={sidiImage} id="system-modal" title='Кнопка "Открыть"'/>

Открывается меню просмотра словаря (<ImageLink to="preview-dictionaries"/>). Напротив наименования помещения прописаны параметры положения расчетной точки в соответствии с нормативной базой.

<Image image={slovarImage} id="preview-dictionaries" title="Просмотр словаря"/>


Нажмем на стрелку в столбце *"Имя"*. (<ImageLink to="names-modal"/>)

<Image image={nameImage} id="names-modal" title="Переход к списку имен"/>

В открывшемся меню перечислены имена, при использовании которых в проекте, помещение автоматически будет определено к соответствующему типу сервисом (<ImageLink to="names-modal-2"/>).

Этот список можно пополнить, обратившись в техническую поддержку.

<Image image={typenamesImage} id="names-modal-2" title="Просмотр имен для типа помещения"/>

Вернемся в *"Список словарей"*. Создадим пользовательский словарь. Для этого нужно нажать на кнопку *"+ Добавить словарь"* (<ImageLink to="new-dictionary"/>).

<Image image={newdicImage} id="new-dictionary" title='Кнопка "Добавить словарь"'/>

В пустой строке вбиваем название пользовательского словаря. Для создания нажимаем на зеленую галочку (<ImageLink to="add-dictionary"/>).

<Image image={newnameImage} id="add-dictionary" title="Создание словаря"/>

Новый словарь сохранится и отобразится в списке после системных. Для его редактирования нажмем 3 точки и "*Открыть"* (<ImageLink to="open-dictionary"/>).

<Image image={opendicImage} id="open-dictionary" title='Кнопка "Открыть"'/>

Нажимаем *"Добавить новый тип помещения"* (<ImageLink to="edit-room-types"/>).

<Image image={newtypeImage} id="edit-room-types" title='Кнопка "Добавить новый тип помещения"'/>

Вводим соответствующие типу помещения нормативные показатели (<ImageLink to="edit-dictionary"/>).

<Image image={newpomImage} id="edit-dictionary" title="Редактирование словаря"/>

Откроем редактор имен, щелкнув на стрелку в одноименном столбце (<ImageLink to="room-names-list"/>).

<Image image={newnmImage} id="room-names-list" title="Переход к списку имен"/>

Нажимаем кнопку *"Добавить новое имя"* (<ImageLink to="add-new-room-name"/>).

<Image image={newpomnameImage} id="add-new-room-name" title='Кнопка "Добавить новое имя"'/>

В строке вбиваем имя помещения, используемое в проекте. Нажимаем на зеленую галочку для сохранения (<ImageLink to="add-new-name"/>). Аналогично добавляем потенциально возможные вариации имен для редактируемого типа помещения.

<Image image={newnpImage} id="add-new-name" title="Создание имени"/>

Созданные для типа помещения имена отобразятся в виде списка (<ImageLink to="names-list"/>).

<Image image={someImage} id="names-list" title="Список имен"/>

Вернемся в режим просмотра словаря (нажатием на стрелку в верхнем левом углу). Количество созданных имен отобразится в столбце *"Имя"*. Впоследствии этот список можно дополнять. Нажимаем крестик в правом верхнем углу, для выхода из меню редактирования.

При корректном создании словарей, над иконкой появится красная точка (<ImageLink to="rooms-tab-after-dicts"/>) которая будет означать наличие изменений. Чтобы их применить, нажимаем на кнопку "синхронизировать" (<ImageLink to="rooms-tab-after-dicts"/>). После синхронизации, к соответствующим помещениям будут применены настройки словаря.
