## Основные настройки КЕО. Коэффициенты CN, MF.

Во вкладке “Настройки” пользователь указывает номер административного района (его можно определить в документации), в котором находится объект, автоматически устанавливается коэффициент эксплуатации - МF. (при наведении на значок информации (справа от коэффициента), пользователь увидит подсказку, что обозначает данный коэффициент) (рис. 57).

## Общий коэффициент отражения фасада

Пользователю необходимо поочередно выбрать каждое здание, в дополнительно открывшейся вкладке указать для них ρф - общий коэффициент отражения фасада (рис. 59).

<image image={eImage} width="70%" title="Рисунок 59 - Настройка СКОФ "/>

Перед выбором коэффициента, необходимо задать его параметры. При нажатии на строку “Общ коэф отр фасада” появляется выбор “Редактирование”, пользователю необходимо нажатием открыть окно редактирования.


Открывается окно “Список Коэффициентов отрожения фасада”. Здесь будут отображаться созданные пользователем варианты фасадов (рис. 60). При необходимости создания нового, пользователь кликает на соответствующую кнопку (рис. 60).

<image image={rImage} width="100%" title="Рисунок 60 - Создание нового СКОФ "/>

Далее пользователь выбирает *“Добавить материал фасада”* (рис. 61). 


<image image={tImage} width="100%" title="Рисунок 61 - Добавить материал фрагмента фасада "/>


В строке, выбираем материал фрагмента фасада, соответствующий материалу затеняющего фасада здания, коэффициент отражения материала будет указан автоматически. Также пользователю нужно ввести весовой коэффициент - площадь данного фрагмента (в м. кв., рис. 62).


<image image={yImage} width="100%" title="Рисунок 62 - Cоздание и настройка средневзвешенного коэффициента отражения фасада "/>

После ввода данных пользователь может сохранить созданный элемент фасада или отменить это действие (рис. 63).
При необходимости, аналогичным образом добавляем дополнительные материалы. Итоговый коэффициент будет рассчитан автоматически.

<image image={uImage} width="100%" title="Рисунок 63 - Сохранение настройки средневзвешенного коэффициента отражения фасада/отмена создания"/>

Нажимаем на стрелку в верхнем левом углу, вычисленный коэффициент сохранится автоматически (рис. 64).


<image image={iImage} width="100%" title="Рисунок 64 - Сохранение средневзвешенного коэффициента отражения фасада"/>


После этого шага пользователь также может сохранить или отменить создание.


После сохранения коэффициента можно закрыть окно.
В строке выбора пользователь выбирает созданный средневзвешенный коэффициент отражения фасада (рис. 65).

<image image={pImage} width="45%" title="Рисунок 65 - Выбор значения средневзвешенного коэффициента отражения фасада"/>

## Назначение коэффициентов τ

Ниже, в этом же окне, показан список типов окон, спроектированных в программе Revit, для каждого из них нужно указать значения коэффициентов, которые влияют на уровень пропускания света в различных конструкциях (рис. 66, все значения можно определить в документации).

Коэффициенты можно вводить сразу для нескольких типов окон с помощью мультиселекта. Чтобы это сделать зажимаем "ctrl", снять выделение с окна можно так же при зажатом "ctrl"  Чтобы выделить диапазон, зажимаем "shift".

При выделеннии, соответствующие типы окон подсвечиваются в сцене.

<image image={aImage} width="80%" title="Рисунок 66 - Выбор коэффициентов пропускания света"/>

### Коэффициент τ1

τ1 - остекление. Пользователь выбирает тип остекления (формула окна), для каждого типа окна доступен один или несколько вариантов коэффициента, нужно выбрать его самостоятельно.

Также при отсутствии вашего типа остекления в нормативной базе, можно создать формулу остекления через *"Редактирование"*.

Нажимаем *"Создать формулу остекления"*. (рис. 67) Активируется строка редактирования.

<image image={osttImage} width="100%" title="Рисунок 67 - Создание формулы окна"/>

Вводим название формулы, при необходимости подгружаем сертификат. Нажимаем на "добавить" и вписываем соответствующие вашему типу остекления показатели. (рис. 68)

<image image={ostsImage} width="100%" title="Рисунок 68 - Создание формулы окна"/>

Для сохранения нажимаем зеленую галочку (рис. 69).  
Теперь созданный вами коэффициент можно выбрать в общем выпадающем списке.


<image image={osImage} width="100%" title="Рисунок 69 - Сохранение формулы окна"/>

### Коэффициент τ2

τ2 - переплет. Необходимо создать тип переплета для расчета коэффициента. В строке выбора переплета пользователь нажимает вариант на *"Редактирование"* . Открывается окно редактирования, нажимаем *“Создать тип окна”*. Открывается калькулятор расчета коэффициента. Вбиваются габаритные значения в необходимую ячейку, указывается название (рис. 70).


В правой нижней части окна можно сохранить или отменить создание.

<image image={sImage} width="100%" title="Рисунок 70 - Окно создания коэффициента τ2 "/>
<image image={dImage} width="100%" title="Рисунок 71 - Калькулятор создания коэффициента τ2"/>

Задаем остальные коэффициенты (рис. 71). 
### Коэффициенты τ2, τ3, τ4

τ3- несущие конструкции. При боковом освещении t3=1;  
τ4- затеняющие конструкции. Пользователь также указывает, какие конструкции соответствуют выбранному типу окна. По умолчанию коэффициент равен 1;  
τ5- наличие или отсутствие защитной сетки. По умолчанию коэффициент равен 1.  

Пользователь проделывает эти действия для каждого типа окна, а далее для всех зданий. Мультиселект позволяет задавать τ сразу для нескольких типов окон. На рисунке выделено 3 типа окна. Они подсвечиваются синим цветом.

После того, как выставлены все коэффициенты, можно закрыть поле настроек коэффициентов здания с помощью кнопки *"Применить"* (рис. 72).

<image image={fImage} width="70%" title="Рисунок 72 - Применение настроек коэффициентов"/>

Выбор объекта для расчета происходит через дерево объектов. Во вкладке “Дерево объекта” (рис. 73) можно выбрать как все здания сразу, так и отдельный этаж, квартиру или помещение.

## Настройка положения расчетной точки КЕО.

Для корректного расчета КЕО необходимо задать каждому помещению свой тип. Настройка типов помещения в сервисе производится автоматически (в соответствии с существующей базой словарей). Также есть возможность создать свои словари с необходимыми параметрами. 

Во вкладке КЕО выбираем здание, в котором находится нужное помещение (рис. 74).

<image image={tk1Image} width="35%" title="Рисунок 74 - Выбор здания"/>

Переходим во вкладку *Помещения* (рис. 75).

<image image={tk2Image} width="35%" title="Рисунок 75 - Вкладка помещения"/>

В этом окне отображаются этажи и помещения, относящиеся к ним. 
Помещения в сцене автоматически распределяются на 3 категории (рис 76).

<image image={tkk2Image} width="35%" title="Рисунок 76 - Категории помещений"/>

![](../../resources/frame/red.png) -  **Тип не указан** (например, в автоматическом подборе словаря, определении границ помещения);    
![](../../resources/frame/yell.png) -  **Нужно выбраь тип** (например, необходимо произвести выбор между несколькими словарями для указания типа помещения);  
![](../../resources/frame/gre.png) - **Тип указан** .  (тип автоматически определился в сответствии с системным/пользовательским словарем).


При нажатии на категорию можно увидеть все определенные к ней помещения.

Изучить системные словари (созданные в соответствии с действующей нормативной документацией) или создать пользовательские можно через опциональное меню, которое открывается нажатием кнопки *"Словари"* (рис. 77).

<image image={dictionImage} width="35%" title="Рисунок 77 - Кнопка Словари"/>

В открывшемся окне список системных словарей. (рис. 78)

<image image={sisdictImage} width="100%" title="Рисунок 78 - Список словарей"/>

Нажимаем на 3 точки. Пользователь может открыть интересующий его системный словарь и изучить его параметры.(рис. 79)

<image image={sidiImage} width="100%" title="Рисунок 79 - Кнопка открыть"/>

Открывается меню просмотра словаря. (рис. 80). Напротив наименования помещения прописаны параметры положения расчетной точки в соответствии с нормативной базой. 

<image image={slovarImage} width="100%" title="Рисунок 80 - Просмотр словаря"/>


Нажмем на стрелку в столбце *"Имя"*. (рис. 81)

<image image={nameImage} width="100%" title="Рисунок 81 - Переход к списку имен"/>

В открывшемся меню перечислены имена, при использовании которых в проекте, помещение автоматически будет определено к соответствующему типу сервисом. (рис. 82) (Этот список можно пополнить, обратившись в техническую поддержку). 

<image image={typenamesImage} width="100%" title="Рисунок 82 - Просмотр имен для типа помещения"/>

<image image={newdicImage} width="100%" title="Рисунок 83 - Кнопка Добавить словарь"/>

<image image={newnameImage} width="100%" title="Рисунок 84 - Создание словаря"/>

<image image={opendicImage} width="100%" title="Рисунок 85 - Кнопка Открыть"/>

<image image={newtypeImage} width="100%" title="Рисунок 86 - Кнопка Добавить новый тип помещения"/>
