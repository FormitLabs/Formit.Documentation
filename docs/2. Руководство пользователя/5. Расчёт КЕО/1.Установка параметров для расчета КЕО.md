## Основные настройки КЕО. Коэффициенты C<sub>N</sub>, MF.

Во вкладке “Настройки” пользователь указывает номер административного района для расчета коэффициента C<sub>N</sub> (его можно определить в документации), в котором находится объект, автоматически устанавливается коэффициент эксплуатации - МF. (при наведении на значок информации (справа от коэффициента), пользователь увидит подсказку, что обозначает данный коэффициент) (рис. 64).

Вводятся значения MF только для угла наклона светопропускающего материала к горизонту в пределах 76°-90° (Боковое КЕО).

## Общий коэффициент отражения фасада

Пользователю необходимо поочередно выбрать каждое здание, в дополнительно открывшейся вкладке указать для них ρ<sub>ф</sub> - общий коэффициент отражения фасада (рис. 66).

<Image image={eImage} width="70%" title={<>Рисунок 66 - Настройка ρ<sub>ф</sub></>}/>

Перед выбором коэффициента, необходимо задать его параметры. При нажатии на строку “Общ коэф отр фасада” появляется выбор “Редактирование”, пользователю необходимо нажатием открыть окно редактирования.


Открывается окно “Список Коэффициентов отражения фасада”. Здесь будут отображаться созданные пользователем варианты фасадов (рис. 67). При необходимости создания нового, пользователь нажимает на соответствующую кнопку (рис. 67).

<Image image={rImage} width="100%" title={<>Рисунок 67 - Создание нового ρ<sub>ф</sub></>}/>

Далее пользователь выбирает *“Добавить материал фасада”* (рис. 68). 


<Image image={tImage} width="100%" title="Рисунок 68 - Добавить материал фрагмента фасада "/>


В строке, выбираем материал фрагмента фасада, соответствующий материалу затеняющего фасада здания. Также пользователю нужно выбрать коэффициент отражения фасада и ввести весовой коэффициент - площадь данного фрагмента в м. кв. (рис. 69).

База материалов заимствована из нормативной документации (СП 52, СП 367). 

<Image image={yImage} width="100%" title="Рисунок 69 - Создание и настройка средневзвешенного коэффициента отражения фасада "/>

После ввода данных пользователь может сохранить созданный элемент фасада или отменить это действие (рис. 70).
При необходимости, аналогичным образом добавляем дополнительные материалы. Итоговый коэффициент будет рассчитан автоматически.

<Image image={uImage} width="100%" title="Рисунок 70 - Сохранение настройки средневзвешенного коэффициента отражения фасада/отмена создания"/>

<Image image={iImage} width="100%" title="Рисунок 71 - Сохранение средневзвешенного коэффициента отражения фасада"/>


После сохранения коэффициента можно закрыть окно.
В строке выбора пользователь выбирает созданный средневзвешенный коэффициент отражения фасада (рис. 72).

<Image image={pImage} width="45%" title="Рисунок 72 - Выбор значения средневзвешенного коэффициента отражения фасада"/>

## Назначение коэффициентов τ

Ниже, в этом же окне, показан список типов окон, спроектированных в программе Revit, для каждого из них нужно указать значения коэффициентов, которые влияют на уровень пропускания света в различных конструкциях (рис. 73), все значения можно определить в документации.

Коэффициенты можно вводить сразу для нескольких типов окон с помощью мультиселекта. Чтобы это сделать зажимаем "ctrl", снять выделение с окна можно так же при зажатом "ctrl". Чтобы выделить диапазон, зажимаем "shift".

При выделении, соответствующие типы окон подсвечиваются в сцене.

<Image image={aImage} width="80%" title="Рисунок 73 - Выбор коэффициентов пропускания света"/>


Коэффициенты τ настраиваются для всех витражей в проекте одновременно (рис. 74).  

<Image image={glaImage} width="50%" title="Рисунок 74 - Выбор коэффициентов пропускания света для витражей"/>

### Коэффициент τ<sub>1</sub>

τ<sub>1</sub> - остекление. Пользователь выбирает тип остекления (формула окна), для каждого типа окна доступен один или несколько вариантов коэффициента, нужно выбрать его самостоятельно.

Также при отсутствии вашего типа остекления в нормативной базе, можно создать формулу остекления через *"Редактирование"*.

Нажимаем *"Создать формулу остекления"*. (рис. 75) Активируется строка редактирования.

<Image image={osttImage} width="100%" title="Рисунок 75 - Создание формулы окна"/>

Вводим название формулы, при необходимости подгружаем сертификат. Нажимаем на "добавить" и вписываем соответствующие вашему типу остекления показатели. (рис. 76)

<Image image={ostsImage} width="100%" title="Рисунок 76 - Создание формулы окна"/>

Для сохранения нажимаем зеленую галочку (рис. 77).  
Теперь созданный вами коэффициент можно выбрать в общем выпадающем списке.


<Image image={osImage} width="100%" title="Рисунок 77 - Сохранение формулы окна"/>

### Коэффициент τ<sub>2</sub>

#### Для окон

τ<sub>2</sub> - переплет. Необходимо создать тип переплета для расчета коэффициента. В строке выбора переплета пользователь нажимает вариант на *"Редактирование"*. Открывается окно редактирования, нажимаем *“Создать тип окна”* (рис. 78). Открывается калькулятор расчета коэффициента. Вбиваются габаритные значения в необходимую ячейку, указывается название.
Габариты окон указываются в метрах (рис. 79).

<Image image={sImage} width="100%" title={<>Рисунок 78 - Окно создания коэффициента τ<sub>2</sub></>} />
<Image image={dImage} width="100%" title={<>Рисунок 79 - Калькулятор создания коэффициента τ<sub>2</sub></>} />

При нажатии клавиши *"Добавить блок"* вы сможете указать габариты балконного проема (рис. 80). 

<Image image={slgtImage} width="100%" title="Рисунок 80  - Создание формулы окна"/>

При нажатии клавиши *"Задать значение вручную"* пользователь может ввести значение τ<sub>2</sub> из списка СП 367.1325800.2017 Изм.2 табл. А.19 (рис. 81). 

<Image image={vrmImage} width="100%" title="Рисунок 81 - Создание формулы окна"/>

В правой нижней части окна можно сохранить или отменить создание.

#### Для витражей

τ<sub>2</sub> - при выгрузке модели  сервис  автоматически определяет габариты витража, площадь импостов, поэтому необходимо задать только коэффициент отражения переплёта p. Его значение вводится вручную в зависимости от материала.

<Image image={gla2Image} width="50%" title="Рисунок 82 - Коэффициент p для витража "/>

Если не ввести коэффициент p и запустить расчет, то на экране появится предупреждение (рис. 83).

<Image image={t2pImage} width="50%" title="Рисунок 83 - Предупреждение"/>

### Коэффициенты τ<sub>3</sub>, τ<sub>4</sub>, τ<sub>5</sub>

τ<sub>3</sub> - несущие конструкции. При боковом освещении τ<sub>3</sub>=1;  
τ<sub>4</sub> - затеняющие конструкции. Пользователь также указывает, какие конструкции соответствуют выбранному типу окна. По умолчанию коэффициент равен 1;  
τ<sub>5</sub> - наличие или отсутствие защитной сетки. По умолчанию коэффициент равен 1.  


Пользователь проделывает эти действия для каждого типа окна, а далее для всех зданий. Мультиселект позволяет задавать τ сразу для нескольких типов окон. На рисунке выделено 3 типа окна. Они подсвечиваются синим цветом.

После того как выставлены все коэффициенты, можно закрыть поле настроек коэффициентов здания с помощью кнопки *"Применить"* (рис. 84).

<Image image={fImage} width="70%" title="Рисунок 84 - Применение настроек коэффициентов"/>

Для создания коэффициента перейдите в *Редактирование*(рис. 85). Нажмите на кнопку *Создать коэффициент отражения внутренних поверхностей помещения*(рис. 86)

Сервис автоматически производит расчёт данного коэффициента, значения выводятся в отчёт для каждого помещения.

## Настройка положения расчетной точки КЕО. 

Для корректного расчета КЕО необходимо задать каждому помещению свой тип. Настройка типов помещения в сервисе производится автоматически (в соответствии с существующей базой словарей). Также есть возможность создать свои словари с необходимыми параметрами. 

Во вкладке КЕО выбираем здание, в котором находится нужное помещение (рис. 90).

<Image image={tk1Image} width="35%" title="Рисунок 90 - Выбор здания"/>

Переходим во вкладку *Помещения* (рис. 91).

<Image image={tk2Image} width="35%" title="Рисунок 91 - Вкладка помещения"/>

В этом окне отображаются этажи и помещения, относящиеся к ним. 
Помещения в сцене автоматически распределяются на 3 категории (рис. 92).

<Image image={tkk2Image} width="35%" title="Рисунок 92 - Категории помещений"/>

![](../../resources/frame/red.png) - **Тип не указан** (например, в автоматическом подборе словаря, определении границ помещения);  
![](../../resources/frame/yell.png) - **Нужно выбрать тип** (например, необходимо произвести выбор между несколькими словарями для указания типа помещения);  
![](../../resources/frame/gre.png) - **Тип указан** .  (тип автоматически определился в соответствии с системным/пользовательским словарем).

Вернемся в режим просмотра словаря (нажатием на стрелку в верхнем левом углу). Количество созданных имен отобразится в столбце *"Имя"*. Впоследствии этот список можно дополнять. Нажимаем крестик в правом верхнем углу, для выхода из меню редактирования.

При корректном создании словарей, над иконкой появится красная точка (рис. 109) которая будет означать наличие изменений. Чтобы их применить, нажимаем на кнопку "синхронизировать" (рис. 109) После синхронизации, к соответствующим помещениям будут применены настройки словаря.
