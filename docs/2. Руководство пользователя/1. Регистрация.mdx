Для начала пользования сервисом *“Altec Insolations”* необходима регистрация пользователя. Регистрация осуществляется администратором компании Altec, после оформления подписки.

После подтверждения подписки пользователь получает логин и пароль для входа на сервис. В окне для входа в сервис пользователь вводит свои данные (рис. 1).

<image image={rvImage10} width="40%" title="Рисунок 1 - Окно регистрации"/>

Если данные введены корректно, пользователь попадает на *главный экран сервиса Altec Insolations*. На панели слева расположены две вкладки - *“Аккаунт“* и *“Мои продукты“*.

Во вкладке *“Аккаунт”* размещены личные данные пользователя (рис. 2). Эти поля доступны для самостоятельного заполнения (имя, фамилия, дата рождения, электронный адрес, название компании, фото пользователя).

<image image={lkImage} width="100%" title="Рисунок 2 - Вкладка аккаунт"/> 

Во вкладке *“Мои продукты”* (рис. 3) размещены продукты пользователя - *Altec Insolations* - сама программа для расчета инсоляции и КЕО, и *Revit Export* - плагин для экспорта модели из Ревит в сервис.

<image image={moiprImage} width="100%" title="Рисунок 3 - Вкладка мои продукты"/>
