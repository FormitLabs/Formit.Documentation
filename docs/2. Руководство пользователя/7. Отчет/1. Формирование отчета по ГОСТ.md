В верхней части над сценой есть кнопка, позволяющая создать отчёт. Нажимаем *"Сформировать отчет"* (рис.137). Появляется окно *“Формирование отчёта”*. 
Результаты расчета можно сформировать в общий отчет, а также вывести раздельно. 

<image image={button2Image} width="100%" title="Рисунок 137 - Кнопка Сформировать отчет"/>

К формированию, соответственно, доступны только опции, просчитанные вами в сервисе (рис.138). Сформируем общий отчет. 

Выбираем  *“Инсоляция зданий”*, *"Расчет КЕО"* и *"Инсоляция площадок"*. 

<image image={otchgostImage} width="100%" title="Рисунокт 138 - Выбор опций"/>

Вы можете выбрать отчет в двух вариантах: *"Отчет по старому форму"* и *"Отчет по ГОСТ"*
Выбираем *«Создать отчет по ГОСТУ»*. (рис. 139).


<image image={nachaloImage} width="100%" title="Рисунок 139 - Кнопка Сформировать отчет"/>

### 1 ШАГ *Титульная страница*  

**Заголовок, штамп.**

Заполняем строку *“Заголовок отчета”*.
Вводим данные штампа. Есть возможность его редактирования путем добавления и удаления строк. Нажимаем *“Продолжить”* (рис. 140).


<image image={titulgostImage} width="100%" title="Рисунок 140 -  Настройки Титульной страницы "/>
<image image={gost25Image} width="80%" title="Рисунок 140 - Превью Титульной страницы "/>

В *"Настройках отображения"* Вы можете отключить галочку напротив *"Отображать титульную страницу, рамки и инженерный штамп"*. Тогда отчет будет выгружен с пустым листом. 

Результаты Инсоляции будут выводится по солнечному времени. 


### 2 ШАГ *Введение*

**Методика расчета, исходные данные.**

Заполняем поле *“Введение”*. Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели (рис. 141).

Далее описана методика расчета (рис.142). Информация об исходных данных генерируется автоматически, изменить её можно в командном меню в разделе *“Настройки”*. Обновление настроек повлечет изменение результатов инсоляции в отчёте.

**Вывод о результатах.**

Заполняем поле *“Заключение”* (рис.149). Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели.

### 7 ШАГ *Графические планы расчетных этажей*

Нажимаем кнопку *Добавить*.

В автоматически сформированном списке объектов из файла RVT выбираем здание. Далее выбираем этаж, либо группу этажей, для которых необходимо сгенерировать сечение. 

Нажимаем зеленую галочку для сохранения (рис.151).

<image image={grafplgostImage} width="100%" title="Рисунок 151 - Создание графического плана"/>
<image image={plangostImage} width="100%" title="Рисунок 152 - Превью графического плана"/>
<image image={tablplgostImage} width="60%" title="Рисунок 152.1 - Превью графического плана"/>

Сформированные планы будут отображаться списком.

Вверху списка приложений - кнопка "Добавить".

С её помощью, при необходимости, можно выбрать другие здания из сборки и подгружать относящиеся к нему сечения, по тому же алгоритму.

8 ШАГ *Ситуационный план* 

На данном шаге у пользователя есть возможность сгенерировать графический план сцены, который представляет собой сборку всех зданий на сцене и отображение лучей с информацией о продолжительности инсоляции выбранной расчетной точки. Для этого нужно нажать кнопку "+ Добавить" (рис.153)

<image image={step7Image} width="100%" title="Рисунок 153- Кнопка Добавить план"/>

Данный блок позволяет: (рис.154)

- настроить позиционирование камеры на здании или на центре сцены при создании листа;
- выбрать необходимый масштаб и формат листа;
- автоматическая генерация таблицы, содержащую в себе информацию о продолжительности инсоляции расчетных точек.

<image image={step77Image} width="100%" title="Рисунок 154 - Настройка графического плана"/>
<image image={tablsitImage} width="60%" title="Рисунок 155 - Превью ситуационного плана сцены"/>
<image image={sitplanImage} width="100%" title="Рисунок 155.1 - Превью ситуационного плана сцены М 1:200"/>

### 9 ШАГ *Готово*

**Сохранить шаблон, скачать отчёт.**

Ваш отчёт готов! Нажимаем *"Сформировать отчет"*. (рис.156). 

<image image={step6Image} width="100%" title=" Рисунок 156 - Формирование отчета"/>

Отчет можно сохранить в PDF. Файл будет скачан, без дальнейшей возможности редактирования.
