***

В верхней части над сценой есть кнопка, позволяющая создать отчёт. Нажимаем *"Сформировать отчет"* (<ImageLink to="open-reports-modal"/>). Появляется окно *“Формирование отчёта”*.

Результаты расчета можно сформировать в общий отчет, а также вывести раздельно. 

<Image image={buttonImage} id="open-reports-modal" title='Кнопка "Сформировать отчет"'/>

К формированию, соответственно, доступны только опции, просчитанные вами в сервисе (<ImageLink to="report-modal"/>).

Сформируем общий отчет.

<Image image={otchImage} id="report-modal" title="Окно создания отчетов"/>

Выбираем пункты *“Инсоляция зданий”*, *"Расчет КЕО"* и *"Инсоляция площадок"* (<ImageLink to="selected-options"/>).

<Image image={otch1Image} id="selected-options" title="Выбор опций"/>

Вы можете выбрать отчет в двух вариантах: *"Отчет по старому формату"* и *"Отчет по ГОСТу"*.
Выбираем *"Создать отчет в старом формате"* (<ImageLink to="legacy-report"/>).

<Image image={vstaromImage} id="legacy-report" title='Кнопка "Создать отчет в старом формате"'/>

### 1. *Титульная страница*

**Заголовок, штамп.**

Заполняем строку *“Заголовок отчета”*.
Вводим данные штампа. Есть возможность его редактирования путем добавления и удаления строк. Нажимаем *“Продолжить”* (<ImageLink to="title-step"/>).

<Image image={step1Image} id="title-step" title='Блок "Титульная страница"'/>
<Image image={str1Image} id="title-step-preview" width="60%" title="Превью титульной страницы"/>

В *"Настройках отображения"* вы можете отключить галочку напротив *"Отображать титульную страницу, рамки и инженерный штамп"*. Тогда отчет будет выгружен с пустым листом.

Там же можно настроить использование солнечного времени для результатов инсоляции помещений и площадок. 

<Image image={bezshtampImage} id="without-borders-preview" width="60%" title="Без титульной страницы"/>

### 2. *Введение*

**Методика расчета, исходные данные.**

Заполняем поле *“Введение”*. Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели (<ImageLink to="intoduction-step"/>).

Далее описана методика расчета (<ImageLink to="intoduction-preview"/>). Информация об исходных данных генерируется автоматически, изменить её можно в командном меню в разделе *“Настройки”*. Обновление настроек повлечет изменение результатов инсоляции в отчёте.

<Image image={step2Image} id="intoduction-step" title='Блок "Введение"'/>
<Image image={vvedenieImage} id="intoduction-preview" width="60%" title="Превью введения"/>
<Image image={vvedenie2Image} id="intoduction-preview-continuation" width="60%" title="Продолжение превью введения"/>

###  3. *Расчёт инсоляции*

**Типы помещения, настройки отображения.**

На этом этапе вы выбираете необходимые для отчета помещения с помощью фильтра и можете настроить отображение. Можно, по желанию, добавить к отчёту сводную таблицу, инсоляционную линейку, пометить цветом результаты инсоляцию. По умолчанию эти опции отключены (<ImageLink to="insolation-step"/>).

<Image image={step3Image} id="insolation-step" title='Блок "Расчет инсоляции"'/>
<Image image={rezultImage} id="insolation-preview" width="60%" title="Превью расчета инсоляции"/>

### 4. *Инсоляция площадок*

**Выбор площадок, настройки отображения.**

Выбираем площадки, результаты расчета которых нам интересны для выведения в отчет, при необходимости, помечаем цветом. (<ImageLink to="areas-step"/>)

<Image image={plImage} id="areas-step" title='Блок "Инсоляция площадок"'/>
<Image image={preplImage} id="areas-preview" width="70%" title="Превью расчета инсоляции площадок"/>

### 5. *Расчет КЕО*

**Расчетные этажи, выгрузка планов.**

На этом шаге нужно посекционно выбрать типы помещений, которые войдут в отчёт (<ImageLink to="keo-step"/>). Можно добавить схемы кео, тогда по каждому помещению будут выгружены план и разрез с расположением расчетной точки.

При выборе "Расширенная версия отчета" в отчете будет более подробно расписаны все коэффициенты расчета и промежуточные формулы (<ImageLink to="keo-preview"/>).

<Image image={KEOImage} id="keo-step" title='Блок "Расчет КЕО"'/>
<Image image={prekeoImage} id="keo-preview" width="70%" title="Превью расчета КЕО"/>

### 6. *Заключение*

**Вывод о результатах.**

Заполняем поле *“Заключение”* (<ImageLink to="conclusion-step"/>). Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели.

<Image image={step4Image} id="conclusion-step" title='Блок "Заключение"'/>
<Image image={prezImage} id="conclusion-step-preview" width="70%" title="Превью заключения"/>

### 7. *Графические планы*

Нажимаем кнопку *Добавить*.

В автоматически сформированном списке объектов из файла RVT выбираем здание. Далее выбираем этаж, либо группу этажей, для которых необходимо сгенерировать сечение. 

Нажимаем зеленую галочку для сохранения (<ImageLink to="graphic-plans-step"/>).

<Image image={step5Image} id="graphic-plans-step" title="Создание графического плана"/>
<Image image={planImage} id="graphic-plans-preview" title="Превью графического плана"/>
<Image image={tablplImage} id="graphic-plans-table-preview" width="60%" title="Превью сводной таблицы графического плана"/>

Сформированные планы будут отображаться списком.

Вверху списка приложений находится кнопка *"Добавить"*.

С её помощью, при необходимости, можно выбрать другие здания из сборки и подгружать относящиеся к нему сечения, по тому же алгоритму.

### 8. *Ситуационные планы*

На данном шаге у пользователя есть возможность сгенерировать графический план сцены, который представляет собой сборку всех зданий на сцене и отображение лучей с информацией о продолжительности инсоляции выбранной расчетной точки. Для этого нужно нажать кнопку "+ Добавить" (<ImageLink to="add-plan"/>).

<Image image={step7Image} id="add-plan" title='Кнопка "Добавить план"'/>

Возможности данного блока (<ImageLink to="plans-setup"/>):

- Настройка позиционирования камеры на здании или на центре сцены при создании листа;
- Выбор необходимого масштаба и формата листа;
- Автоматическое формирование таблицы, содержащей в себе информацию о продолжительности инсоляции расчетных точек.

<Image image={step77Image} id="plans-setup" title="Настройка ситуационного плана"/>
<Image image={votmImage} id="plans-preview" width="60%" title="Превью таблицы"/>
<Image image={grplImage} id="plans-preview-different-scale" title="Превью ситуационного плана сцены"/>

### 9. *Формирование отчета*

Конфигурация вашего отчёта готова! Нажимаем *"Сформировать отчет"* (<ImageLink to="create-report"/>).

<Image image={step6Image} id="create-report" title="Формирование отчета"/>

Отчет можно сохранить в PDF. Файл будет скачан, без дальнейшей возможности редактирования.
