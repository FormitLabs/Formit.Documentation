В верхней части над сценой есть кнопка, позволяющая создать отчёт. Нажимаем *"Сформировать отчет"* (рис. 96). Появляется окно *“Формирование отчёта”*. 
Результаты расчета можно сформировать в общий отчет, а также вывести раздельно. 

<image image={buttonImage} width="100%" title="Рисунок 96 - Кнопка Сформировать отчет"/>

К формированию, соответственно, доступны только опции, просчитанные вами в сервисе. (рис.97) Сформируем общий отчет. 

<image image={otchImage} width="100%" title="Рисунок 97 - Окно создания отчетов"/>

Выбираем  *“Инсоляция зданий”*, *"Расет КЕО"* и *"Инсоляция площадок"* (рис. 98). 

<image image={otch1Image} width="100%" title="Рисунок 98 - Выбор опций"/>

Нажимаем *“Создать”* (рис. 99).

<image image={sozdImage} width="100%" title="Рисунок 99 - Кнопка Создать"/>


### 1 ШАГ *Титульная страница*  

**Заголовок, штамп.**

Заполняем строку *“Заголовок отчета”*.
Вводим данные штампа. Есть возможность его редактирования путем добавления и удаления строк. Нажимаем *“Продолжить”* (рис. 100).

<image image={step1Image} width="100%" title="Рисунок 100 - 1 шаг создания отчета"/>
<image image={str1Image} width="60%" title="Рисунок 101 - Превью титульной страницы"/>

### 2 ШАГ *Введение*

**Методика расчета, исходные данные.**

Заполняем поле *“Введение”*. Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели (рис. 82).

Далее описана методика расчета. Информация об исходных данных генерируется автоматически, изменить её можно в командном меню в разделе *“Настройки”*. Обновление настроек повлечет изменение результатов инсоляции в отчёте.

<image image={step2Image} width="100%" title="Рисунок 102 - 2 шаг создания отчета"/>
<image image={vvedenieImage} width="60%" title="Рисунок 103 - Превью введения"/>

###  3 ШАГ *Расчёт инсоляции*

**Типы помещения, настройки отображения.**

На этом этапе Вы выбираете необходимые для отчета помещения с помощью фильтра и можете настроить отображение. Можно, по желанию, добавить к отчёту сводную таблицу, инсоляционную линейку, пометить цветом результаты инсоляции. По умолчанию эти опции отключены (рис. 104). 

<image image={step3Image} width="100%" title="Рисунок 104 - 3 шаг создания отчета"/>
<image image={rezultImage} width="60%" title="Рисунок 105 - Превью расчета инсоляции"/>

### 4 ШАГ *Расчет КЕО*

**Расчетные этажи, подгрузка планов.**

На этом шаге нужно посекционно выбрать типы помещений, которые войдут в отчёт. (рис. 106)

<image image={KEOImage} width="100%" title="Рисунок 106 - 4 шаг создания отчета"/>
<image image={prekeoImage} width="70%" title="Рисунок 107 - Превью расчета КЕО"/>





### 5 ШАГ *Инсоляция площадок*

**Выбор площадок, настройки отображения.**

Выбираем площадки, результаты расчета которых нам интересны для выведения в отчет, при необходимости, помечаем цветом. (рис. 108)

<image image={plImage} width="100%" title="Рисунок 107 - 5 шаг создания отчета"/>

<image image={preplImage} width="70%" title="Рисунок 108 - Превью расчета площадок"/>



### 6 ШАГ *Вывод*

**Вывод о результатах.**

Заполняем поле *“Вывод”* (рис. 109). Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели.

<image image={step4Image} width="100%" title="Рисунок 109 - 6 шаг создания отчета"/>

<image image={prezImage} width="70%" title="Рисунок 109 - Превью вывода"/>

### 7 ШАГ *Приложение*

**Длбавить сечение, план БТИ.**

Нажимаем кнопку *Добавить приложение*.

В автоматически сформированном списке объектов из файла RVT выбираем здание. Далее выбираем этаж, либо группу этажей, для которых необходимо сгенерировать сечение. 

Планы БТИ можно выгрузить, с помощью кнопки *“План БТИ”*.
Нажимаем *“Добавить сечение”* и нажимаем зеленую галочку для сохранения (рис. 111).

<image image={step5Image} width="100%" title="Рисунок 111 - 7 шаг создания отчета"/>
<image image={planImage} width="100%" title="Рисунок 112 - 7 шаг создания отчета"/>
<image image={tablplImage} width="60%" title="Рисунок 113 - 7 шаг создания отчета"/>

Сформированные планы будут отображаться списком.

Вверху списка приложений - кнопка *"Добавить приложение"*.

С её помощью, при необходимости, можно выбрать другие здания из сборки и подгружать относящиеся к нему сечения, по тому же алгоритму.


### 8 ШАГ *Графическая часть*

**Ситуационный план, сводная таблица.**

На данном шаге у пользователя есть возможность сгенерировать графический план сцены, который представляет из себя сборку всех зданий на сцене и отображение лучей с информацией о продолжительности инсоляции выбранной расчетной точки. Для этого нужно нажать кнопку "+ Добавить план" (рис. 114).

<image image={step7Image} width="100%" title="Рисунок 114 - Кнопка Добавить план"/>

Данный блок позволяет: (рис. 87)

- выбрать нужную расчетную точку для отображения продолжительности инсоляции;
- настроить позиционирование камеры на здании или на центре сцены при создании листа;
- выбрать необходимый масштаб и формат листа;
- добавить таблицу, содержащую в себе информацию о продолжительности инсоляции расчетной точки.

### 9 ШАГ *Готово*

**Сохранить шаблон, скачать отчёт.**

Ваш отчёт готов! Нажимаем *"Сформировать отчет"*. (рис. 118). 

<image image={step6Image} width="100%" title="Рисунок 118 - 9 шаг создания отчета"/>


Отчет можно сохранить в PDF. Файл будет скачан, без дальнейшей возможности редактирования.
