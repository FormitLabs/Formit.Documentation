В верхней части над сценой есть кнопка, позволяющая создать отчёт. Нажимаем *"Сформировать отчет"* (рис. 112). Появляется окно *“Формирование отчёта”*. 
Результаты расчета можно сформировать в общий отчет, а также вывести раздельно. 

<Image image={buttonImage} width="100%" title="Рисунок 112 - Кнопка Сформировать отчет"/>

К формированию, соответственно, доступны только опции, просчитанные вами в сервисе (рис. 113). Сформируем общий отчет. 

<Image image={otchImage} width="100%" title="Рисунок 113 - Окно создания отчетов"/>

Выбираем  *“Инсоляция зданий”*, *"Расчет КЕО"* и *"Инсоляция площадок"* (рис. 114). 

<Image image={otch1Image} width="100%" title="Рисунок 114 - Выбор опций"/>

Вы можете выбрать отчет в двух вариантах: *"Отчет по старому формату"* и *"Отчет по ГОСТу"*
Выбираем *«Создать отчет в старом формате»*. (рис. 115).

<Image image={vstaromImage} width="100%" title="Рисунок 115 - Кнопка создать отчет в старом формате"/>


### 1 ШАГ *Титульная страница*  

**Заголовок, штамп.**

Заполняем строку *“Заголовок отчета”*.
Вводим данные штампа. Есть возможность его редактирования путем добавления и удаления строк. Нажимаем *“Продолжить”* (рис. 116).


<Image image={step1Image} width="100%" title="Рисунок 116 - 1 шаг создания отчета"/>
<Image image={str1Image} width="60%" title="Рисунок 117 - Превью титульной страницы"/> 

В *"Настройках отображения"* вы можете отключить галочку напротив *"Отображать титульную страницу, рамки и инженерный штамп"*. Тогда отчет будет выгружен с пустым листом. 
Там же можно настроить использование солнечного времени для результатов инсоляции помещений и площадок. 

<Image image={bezshtampImage} width="60%" title="Рисунок 118 - Без титульной страницы"/> 

### 2 ШАГ *Введение*

**Методика расчета, исходные данные.**

Заполняем поле *“Введение”*. Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели (рис. 119).

Далее описана методика расчета (рис. 120). Информация об исходных данных генерируется автоматически, изменить её можно в командном меню в разделе *“Настройки”*. Обновление настроек повлечет изменение результатов инсоляции в отчёте.

<Image image={step2Image} width="100%" title="Рисунок 119 - 2 шаг создания отчета"/>
<Image image={vvedenieImage} width="60%" title="Рисунок 120 - Превью введения"/>
<Image image={vvedenie2Image} width="60%" title="Рисунок 120.1 - Методика расчета"/>

###  3 ШАГ *Расчёт инсоляции*

**Типы помещения, настройки отображения.**

На этом этапе вы выбираете необходимые для отчета помещения с помощью фильтра и можете настроить отображение. Можно, по желанию, добавить к отчёту сводную таблицу, инсоляционную линейку, пометить цветом результаты инсоляцию. По умолчанию эти опции отключены (рис. 121). 

<Image image={step3Image} width="100%" title="Рисунок 121 - 3 шаг создания отчета"/>
<Image image={rezultImage} width="60%" title="Рисунок 122 - Превью расчета инсоляции"/>


### 4 ШАГ *Инсоляция площадок*

**Выбор площадок, настройки отображения.**

Выбираем площадки, результаты расчета которых нам интересны для выведения в отчет, при необходимости, помечаем цветом. (рис. 123)

<Image image={plImage} width="100%" title="Рисунок 123 - 5 шаг создания отчета"/>

<Image image={preplImage} width="70%" title="Рисунок 124 - Превью расчета площадок"/>


### 5 ШАГ *Расчет КЕО*

**Расчетные этажи, выгрузка планов.**

На этом шаге нужно посекционно выбрать типы помещений, которые войдут в отчёт (рис. 125). Можно добавить схемы кео, тогда по каждому помещению будут выгружены план и разрез с расположением расчетной точки.

При выборе "Расширенная версия отчета" в отчете будет более подробно расписаны все коэффициенты расчета и промежуточные формулы (рис. 126). 

<Image image={KEOImage} width="100%" title="Рисунок 125 - 4 шаг создания отчета"/>
<Image image={prekeoImage} width="70%" title="Рисунок 126 - Превью расчета КЕО"/>



### 6 ШАГ *Заключение*

**Вывод о результатах.**

Заполняем поле *“Заключение”* (рис. 127). Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели.

<Image image={step4Image} width="100%" title="Рисунок 127 - 6 шаг создания отчета"/>

<Image image={prezImage} width="70%" title="Рисунок 128 - Превью вывода"/>

### 7 ШАГ *Графические планы расчетных этажей*

Нажимаем кнопку *Добавить*.

В автоматически сформированном списке объектов из файла RVT выбираем здание. Далее выбираем этаж, либо группу этажей, для которых необходимо сгенерировать сечение. 

Нажимаем зеленую галочку для сохранения (рис. 129).

<Image image={step5Image} width="100%" title="Рисунок 129 - Создание графического плана"/>
<Image image={planImage} width="100%" title="Рисунок 130 - Превью графического плана"/>
<Image image={tablplImage} width="60%" title="Рисунок 131 - Превью графического плана"/>

Сформированные планы будут отображаться списком.

Вверху списка приложений - кнопка *"Добавить"*.

С её помощью, при необходимости, можно выбрать другие здания из сборки и подгружать относящиеся к нему сечения, по тому же алгоритму.


### 8 ШАГ *Ситуационный план*


На данном шаге у пользователя есть возможность сгенерировать графический план сцены, который представляет собой сборку всех зданий на сцене и отображение лучей с информацией о продолжительности инсоляции выбранной расчетной точки. Для этого нужно нажать кнопку "+ Добавить" (рис. 132).

<Image image={step7Image} width="100%" title="Рисунок 132 - Кнопка Добавить план"/>

Данный блок позволяет: (рис. 133)

- настроить позиционирование камеры на здании или на центре сцены при создании листа;
- выбрать необходимый масштаб и формат листа;
- автоматическая генерация таблицы, содержащую в себе информацию о продолжительности инсоляции расчетных точек.
  

<Image image={step77Image} width="100%" title="Рисунок 133 - Настройка графического плана"/>
<Image image={votmImage} width="60%" title="Рисунок 134 - Превью ситуационного плана сцены"/>
<Image image={grplImage} width="100%" title="Рисунок 135 - Превью ситуационного плана сцены М 1:200"/>

### 9 ШАГ *Готово*

**Сохранить шаблон, скачать отчёт.**

Ваш отчёт готов! Нажимаем *"Сформировать отчет"*. (рис. 136). 

<Image image={step6Image} width="100%" title="Рисунок 136 - 9 шаг создания отчета"/>


Отчет можно сохранить в PDF. Файл будет скачан, без дальнейшей возможности редактирования.
