Вы можете перейти в сервис __*Formit*__ по прямой ссылке или из личного кабинета, вкладка *“Мои продукты”*.

<Image image={glImage} id="main-menu" title="Главная Formit"/>

*[1] - Панель управления (файлы, общий доступ, настройки пользователя, помощь);*<br/>
*[2] - Ранее выгруженные модели;*<br/>
*[3] - Поиск проектов по названию;*<br/>
*[4] - Панель управления проектами (всплывает при нажатии на проект);*<br/>
*[5] - Сортировка по дате выгрузки проекта;*<br/>
*[6] - Выбор отображения проектов;*<br/>
*[7] - Информация о проекте.*<br/>

На главной странице (<ImageLink to="main-menu"/>) вы увидите тестовую модель и ранее экспортированные вами файлы *[2]*. Если выбрать кнопку последние файлы, появится список проектов в порядке очередности по открытию (от недавно открытых к более давним) *[5]*.

Для навигации можно воспользоваться поиском по названию, выбрать удобный режим отображения: *список или таблица* *[6]*.

На значке модели, пользователю показывается превью модели и её вес. 

При нажатии на значок модели появляется панель управления проектами *[4]*. Пользователь видит действия, которые возможно совершить с загруженной моделью, а именно: скачать, переместить в папку, переименовать, удалить.

При нажатии на значок папки появляется панель управления папками *[4]*. Можно переместить в папку файлы, переименовать папку, удалить её.

Открыть модель можно дважды нажав на иконку модели левой кнопкой мыши (далее ЛКМ). 
Открывается окно сервиса Formit.
