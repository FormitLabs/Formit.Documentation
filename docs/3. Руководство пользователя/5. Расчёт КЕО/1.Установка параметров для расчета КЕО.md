Во вкладке “Настройки” пользователь указывает номер административного района (его можно определить в документации), в котором находится объект, автоматически устанавливается коэффициент эксплуатации - МF. (при наведении на значок информации правее коэффициента, пользователь увидит подсказку, что обозначает данный коэффициент) (рис. 53).

<image image={qImage} width="35%" title="Рисунок 53 - Основные настройки"/>

Ниже - список всех зданий, загруженных в сервис (рис.54).

<image image={wImage} width="35%" title="Рисунок 54 - Список зданий"/>

Пользователю необходимо поочередно выбрать каждое здание, в дополнительно открывшейся вкладке указать для них ρф - общий коэффициент отражения фасада (рис. 55).

<image image={eImage} width="70%" title="Рисунок 55 - Настройка СКОФ "/>

Перед выбором коэффициента, необходимо задать его параметры. При нажатии на строку “Общ коэф отр фасада” появляется выбор “Редактирование”, пользователю необходимо нажатием открыть окно редактирования.


Открывается окно “Список СКОФ”. Здесь будут отображаться созданные пользователем варианты фасадов (рис.). При необходимости создания нового СКОФ, пользователь кликает на соответствующую кнопку (рис. 56).

<image image={rImage} width="100%" title="Рисунок 56 - Создание нового СКОФ "/>

Далее пользователь выбирает *“Добавить материал фасада”* (рис. 57). 


<image image={tImage} width="100%" title="Рисунок 57 - Добавить материал фрагмента фасада "/>


В строке, выбираем материал фрагмента фасада, соответствующий материалу затеняющего фасада здания, коэффициент отражения материала будет указан автоматически. Также пользователю нужно ввести весовой коэффициент - площадь данного фрагмента (в м. кв., рис. 58).


<image image={yImage} width="100%" title="Рисунок 58 - Cоздание и настройка СКОФ "/>

После ввода данных пользователь может сохранить созданный элемент фасада или отменить это действие (рис. 59).
При необходимости, аналогичным образом добавляем дополнительные материалы. Итоговый коэффициент будет рассчитан автоматически.

<image image={uImage} width="100%" title="Рисунок 59 - Сохранение настройки СКОФ/отмена создания"/>

Нажимаем на стрелку в верхнем левом углу, вычисленный коэффициент сохранится автоматически (рис. 60).


<image image={iImage} width="100%" title="Рисунок 60 - Сохранение СКОФ"/>


После этого шага пользователь также может сохранить или отменить создание.


После сохранения коэффициента можно закрыть окно.
В строке выбора пользователь выбирает созданный коэффициент СКОФ (рис. 61).

<image image={pImage} width="45%" title="Рисунок 61 - Выбор значения СКОФ"/>

Ниже, в этом же окне, показан список типов окон, спроектированных в программе Revit, для каждого из них нужно указать значения коэффициентов, которые влияют на уровень пропускания света в различных конструкциях (рис. 62, все значения можно определить в документации).


<image image={aImage} width="80%" title="Рисунок 62 - Выбор коэффициентов пропускания света"/>


t1 - остекление. Пользователь выбирает тип остекления (формула окна), для каждого типа окна доступно один или несколько вариантов коэффициента, нужно выбрать его самостоятельно.

Также при отсутствии вашнго типа остекления в нормативной базе, можнл создать фориулу остекления через "редактирование".

Нажимаем "Создать формулу остекления". (рис. 62) Активируется строка редактирования.

<image image={osttImage} width="100%" title="Рисунок 62 - Создание формулы окна"/>

Вводим название формулы, при необходимости подгружаем сертификат. Нажимаем на "добавить" и вписываем соответствующие вашему типу остеклкния показатели. (рис. 62)

<image image={ostsImage} width="100%" title="Рисунок 62 - Создание формулы окна"/>

Для сохранения нажимаем зеленую галочку (рис. 62).  
Теперь созданный вами коэффициент можно выбрать в общем выпадающем списке.


<image image={osImage} width="100%" title="Рисунок 62 - Сохранение формулы окна"/>

t2 - переплет. Необходимо создать тип переплета для расчета коэффициента. В строке выбора переплета пользователь нажимает вариант на *"редактирование"* . Открывается окно, похожее на окно для создания СКОФ. Нажимаем  *“Создать тип окна”*. Открывается калькулятор расчета коэффициента. Вбиваются габаритные значения в необходимую ячейку, указывается название (рис. 63).


В правой нижней части окна можно сохранить или отменить создание.

<image image={sImage} width="100%" title="Рисунок 63 - Окно создания коэффициента t2 "/>
<image image={dImage} width="100%" title="Рисунок 64 - Калькулятор создания коэффициента t2"/>

По аналогии со СКОФ выбираем оставшиеся коэффициенты (рис. 64).  
t3- несущие конструкции. При боковом освещении t3=1;  
t4- затеняющие конструкции. Пользователь также указывает, какие конструкции соответствуют выбранному типу окна. Коэффициент устанавливается автоматически;  
t5- наличие или отсутствие защитной сетки. Коэффициент устанавливается автоматически.  

Пользователь проделывает эти действия для каждого типа окна, а далее для всех зданий.

После того, как выставлены все коэффициенты, можно закрыть поле настроек коэффициентов здания (рис. 65).

<image image={fImage} width="35%" title="Рисунок 65 - Закрытие окна настроек коэффициентов"/>

## Выбор объектов

Выбор объекта для расчета происходит через дерево объектов. Во вкладке “Дерево объекта” (рис. 63) можно выбрать как все здания сразу, так и отдельный этаж, квартиру или помещение. 

<image image={gImage} width="35%" title="Рисунок 66 - Дерево объектов"/>

## Настройка положения расчетной точки КЕО.

В случае, если есть необходимость настроить порожение расчетной точки КЕО, можно это сделать вручную.  
Во вкладке КЕО выбираем здание, в котором находится нужное помещение (рис. 67).

<image image={tk1Image} width="35%" title="Рисунок 67 - Выбор здания"/>

Переходим во вкладку *расчетные точки* (рис. 67).

<image image={tk2Image} width="35%" title="Рисунок 68 - Вкладка Расчетные точки"/>

Выбираем этаж, на котором расположено помещение (рис. 69).

<image image={tk3Image} width="35%" title="Рисунок 69 - Выбор этажа"/>

Выбираем помещение, развернув вложенность этажа (рис. 70).

<image image={tk4Image} width="35%" title="Рисунок 70 - Данные положения расчётной точки в помещении"/>

Открываем контекстное меню *Тип*. Нажимаем *редактировать* (рис. 71).

<image image={tk5Image} width="35%" title="Рисунок 71 - Редактирование параметров расчетной точки"/>

Открывается окно *список типов помещения*. Нажимаем кнопку *"+ Создать новый тип"* (рис. 72).

<image image={tk6Image} width="100%" title="Рисунок 72 - Кнопка Создать новый тип"/>

Даём название помещению. Вводим норимируемое значение для данного типа помещения, задаём высоту точки и глубину (расстояние от точки до дальней от окна стены помещения) положения расчетной точки. Нажимаем *"Сохранить"* (рис. 73).

<image image={tk7Image} width="100%" title="Рисунок 73 - Настройка и сохранение параметров расчетной точки КЕО"/>

Открываем вложенность *Тип*. в самом конце появится созданный нами тип помещения (рис. 74).

<image image={tk8Image} width="35%" title="Рисунок 74 - Созданный тип в контекстном меню"/>

Выбираем его. Заданные данные отобразятся в поле редактируемого помещения. Готово! Мы настроили положение расчетной точки. Эти данные будут применяться при расчете для выбранного помещения (рис. 75).

<image image={tk9Image} width="35%" title="Рисунок 75 - Измененные данные"/>
