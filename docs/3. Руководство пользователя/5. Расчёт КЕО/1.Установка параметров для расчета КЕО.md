Во вкладке “Настройки” пользователь указывает номер административного района (его можно определить в документации), в котором находится объект, автоматически устанавливается коэффициент эксплуатации - МF и коэффициент отражения внутренних поверхностей - Pcp. (при наведении на значок информации правее коэффициента, пользователь увидит подсказку, что обозначает данный коэффициент. рис. 50).

Открывается окно “Список СКОФ”. Здесь будут отображаться созданные пользователем варианты фасадов (рис.). При необходимости создания нового СКОФ, пользователь кликает на соответствующую кнопку (рис. 53).

В верхней части окна указывается название созданного СКОФ, выбирается цвет, величина рассчитывается автоматически (рис. 57).

После сохранения коэффициента можно закрыть окно.
В строке выбора пользователь выбирает созданный коэффициент СКОФ (рис. 58).

<image image={pImage} width="45%" title="Рисунок 58 - Выбор значения СКОФ"/>

Ниже, в этом же окне, показан список типов окон, спроектированных в программе Revit, для каждого из них нужно указать значения коэффициентов, которые влияют на уровень пропускания света в различных конструкциях (рис. 59, все значения можно определить в документации).


<image image={aImage} width="45%" title="Рисунок 59 - Выбор коэффициентов пропускания света"/>


t1 - остекление. Пользователь выбирает тип остекления (формула окна), для каждого типа окна доступно один или несколько вариантов коэффициента, нужно выбрать его самостоятельно, 


t2 - переплет. Необходимо создать тип переплета для расчета коэффициента. В строке выбора переплета пользователь нажимает вариант создание и редактирование. Открывается окно, похожее на окно для создания СКОФ. Выбираем кнопку *“Создать новый тип окна”*. Открывается калькулятор расчета коэффициента. Вбиваются габаритные значения в необходимую ячейку, указывается название (рис. 60).


В нижней части окна нужно сохранить или отменить создание.

<image image={sImage} width="100%" title="Рисунок 60 - Окно создания коэффициента t2 "/>
<image image={dImage} width="100%" title="Рисунок 61 - Калькулятор создания коэффициента t2"/>

По аналогии со СКОФ выбираем оставшиеся коэффициенты.  
t3- несущие конструкции. При боковом освещении t3=1;  
t4- затеняющие конструкции. Пользователь также указывает, какие конструкции соответствуют выбранному типу окна. Коэффициент устанавливается автоматически;  
t5- наличие или отсутствие защитной сетки. Коэффициент устанавливается автоматически.  

Пользователь проделывает эти действия для каждого типа окна, а далее для всех зданий.

После того, как выставлены все коэффициенты, можно закрыть поле настроек коэффициентов здания (рис. 62).
