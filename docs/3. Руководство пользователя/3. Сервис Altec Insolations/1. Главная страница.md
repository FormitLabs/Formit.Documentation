Вы можете перейти в сервис *AltecInsolations* по прямой ссылке или из личного кабинета, вкладка *“Мои продукты”*.

<image image={glImage} width="100%" title="Рисунок 23 - Главная Insolations."/>

*1 - панель управления (файлы и папки, общий доступ, настройки пользователя, помощь);*  
*2 - ранее выгруженные модели;*  
*3 - поиск проектов по названию;*  
*4 - панель управления пронектами;"*  
*5 - сортировка по дате выгрузки проекта"*   
*6 - выбор отображения проектов;*  
*7 - информация о проекте*



На главной странице (рис. 23) вы увидите тестовую модель и ранее экспортированные Вами файлы. Если выбрать кнопку последние файлы, появится список проектов в порядке очередности по открытию (от недавно открытых к более давним).

Для навигации можно воспользоваться поиском по названию, выбрать удобный режим отображения: список или таблица.

Вы можете создать папку, используя кнопку *“Добавить папку”*.  Открывается новое окно - создание папки (рис. 24). После введения названия папку можно создать или отменить ее создание.

<image image={rvImage14} width="55%" title="Рисунок 24 - Окно создания папки"/>

Файлы можно перемещать в папки с помощью перетаскивания или контекстного меню файла модели.

На значке модели (рис. 25), пользователю показывается картинка модели и вес модели, а также кнопки с функцией “Поделиться” и со скрытыми настройками модели. 

<image image={scImage} width="21%" title="Рисунок 25 - Отображение выгруженной модели на Uлавной Insolations."/>

При нажатии на три точки всплывает контекстное меню (рис. 26). Пользователь видит действия, которые возможно совершить с загруженной моделью, а именно: открыть, переименовать, удалить, скачать.

<image image={kontekstImage} width="59%" title="Рисунок 26 -Контекстное меню."/>

Открыть модель можно двумя способами: дважды нажав на иконку модели левой кнопкой мыши (далее ЛКМ), или через контекстное меню - открыть. 
Выбираем один из вариантов, открывается окно сервиса Altec Insolations.
