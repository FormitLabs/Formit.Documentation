В нижней части панели есть кнопка, позволяющая создать отчёт. Нажимаем. Появляется окно *“Формирование отчёта”*. 
Результаты расчета можно сформировать в общий отчет, а также вывести раздельно.

Нам предлагается создать отчет по шаблону выбираем *“Инсоляция зданий”* (рис. 79). Нажимаем *“Создать”* (рис. 80).

<image image={otchImage} width="100%" title="Рисунок 79 - Окно создания отчетов"/>
<image image={otch1Image} width="100%" title="Рисунок 80 - Cоздание отчета по инсоляции"/>

### 1 ШАГ *Титульная страница*  

**Заголовок, штамп.**

Заполняем строку *“Заголовок отчета”*.
Вводим данные штампа. Есть возможность его редактирования путем добавления и удаления строк. Нажимаем *“Продолжить”* (рис. 81).

<image image={step1Image} width="100%" title="Рисунок 81 - 1 шаг создания отчета по инсоляции"/>
<image image={str1Image} width="60%" title="Рисунок 81 - Превью титульной страницы"/>

### 2 ШАГ *Введение*

**Методика расчета, исходные данные.**

Заполняем поле *“Введение”*. Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели (рис. 82).

Далее описана методика расчета. Информация об исходных данных генерируется автоматически, изменить её можно в командном меню в разделе *“Настройки”*. Обновление настроек повлечет изменение результатов инсоляции в отчёте.

<image image={step2Image} width="100%" title="Рисунок 82 - 2 шаг создания отчета по инсоляции"/>
<image image={vvedenieImage} width="60%" title="Рисунок 81 - Превью введения"/>

###  3 ШАГ *Расчёт инсоляции*

**Типы помещения, настройки отображения.**

На этом этапе Вы выбираете необходимые для отчета помещения с помощью фильтра и можете настроить отображение. Можно, по желанию,добавить к отчёту сводную таблицу, инсоляционную линейку, пометить цветом результаты инсоляции. По умолчанию эти опции отключены (рис. 83). 

<image image={step3Image} width="100%" title="Рисунок 83 - 3 шаг создания отчета по инсоляции"/>
<image image={rezultImage} width="60%" title="Рисунок 81 - Превью расчета инсоляции"/>

### 4 ШАГ *Вывод*

**Вывод о рзультатах.**

Заполняем поле *“Вывод”* (рис. 84). Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели.

<image image={step4Image} width="100%" title="Рисунок 84 - 4 шаг создания отчета по инсоляции"/>

### 5 ШАГ *Приложение*

**Длбавить сечение, план БТИ.**

Нажимаем кнопку *Добавить приложение*.

В автоматически сформированном списке объектов из файла RVT выбираем здание. Далее выбираем этаж, либо группу этажей, для которых необходимо сгенерировать сечение. 

Планы БТИ можно выгрузить, с помощью кнопки *“План БТИ”*.
Нажимаем *“Добавить сечение”* и нажимаем зеленую галочку для сохранения (рис. 85).

<image image={step5Image} width="100%" title="Рисунок 85 - 5 шаг создания отчета по инсоляции"/>
<image image={planImage} width="100%" title="Рисунок 85 - 5 шаг создания отчета по инсоляции"/>
<image image={tablplImage} width="60%" title="Рисунок 85 - 5 шаг создания отчета по инсоляции"/>

Сформированные планы будут отображаться списком.

Вверху списка приложений - кнопка *"Добавить приложение"*.

С её помощью, при необходимости, можно выбрать другие здания из сборки и подгружать относящиеся к нему сечения, по тому же алгоритму.


### 6 ШАГ *Графическая часть*

**Ситуационный план, сводная таблица.**

На данном шаге у пользователя есть возможность сгенерировать графический план сцены, который представляет из себя сборку всех зданий на сцене и отображение лучей с информацией о продолжительности инсоляции выбранной расчетной точки. Для этого нужно нажать кнопку "+ Добавить план" (рис. 86).

<image image={step7Image} width="100%" title="Рисунок 86 - Кнопка Добавить план"/>

Данный блок позволяет: (рис. 87)

- выбрать нужную расчетную точку для отображения продолжительности инсоляции;
- настроить позиционирование камеры на здании или на центре сцены при создании листа;
- выбрать необходимый масштаб и формат листа;
- добавить таблицу, содержащую в себе информацию о продолжительности инсоляции расчетной точки.

<image image={votmImage} width="60%" title="Рисунок 87 - Превью графического плана сцены"/>

### 7 ШАГ *Готово*

**Сохранить шаблон, скачать отчёт.**

Ваш отчёт готов! На этом этапе доступно превью всего отчета, его можно сохранить для редактирования в сервисе (рис. 88). 

<image image={step6Image} width="100%" title="Рисунок 88 - 7 шаг создания отчета по инсоляции"/>

Отчет можно сохранить в PDF. Файл будет скачан и заверен электронной подписью, без дальнейшей возможности редактирования.
