В нижней части панели есть кнопка, позволяющая создать отчёт. Нажимаем. Появляется окно *“Формирование отчёта”*. Нам предлагается создать отчет по шаблону выбираем *“Инсоляция зданий”*. Нажимаем *“Создать”*

<image image={otchImage} width="100%" title="Рисунок 67 - Окно создания отчетов"/>
<image image={otch1Image} width="100%" title="Рисунок 68 - Cоздание отчета по инсоляции"/>

### 1 ШАГ

**Титульная страница**

Заполняем строку *“Заголовок отчета”*
Вводим данные штампа. Есть возможность его редактирования путем добавления и удаления строк. Нажимаем *“Продолжить”*

<image image={step1Image} width="100%" title="Рисунок 69 - 1 шаг создания отчета по инсоляции"/>

### 2 ШАГ

**Введение**

Заполняем поле *“Введение”*. Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели.

Далее описана методика расчета. Информация об исходных данных генерируется автоматически, изменить её можно в командном меню в разделе *“Настройки”*. Обновление настроек повлечет изменение результатов инсоляции в отчёте.

<image image={step2Image} width="100%" title="Рисунок 70 - 2 шаг создания отчета по инсоляции"/>

###  3 ШАГ

**Расчет инсоляции**

На этом этапе Вы выбираете необходимые для отчета помещения с помощью фильтра и можете настроить отображение. Можно, по желанию,добавить к отчёту сводную таблицу, инсоляционную линейку, пометить цветом результаты инсоляции. По умолчанию эти опции отключены.

<image image={step3Image} width="100%" title="Рисунок 71 - 3 шаг создания отчета по инсоляции"/>

### 4 ШАГ

**Вывод**

Заполняем поле *“Вывод”*. Текст можно сохранить как шаблон и использовать в последующих версиях отчета для текущей модели.

<image image={step4Image} width="100%" title="Рисунок 72 - 4 шаг создания отчета по инсоляции"/>

### 5 ШАГ

**Приложение**

В автоматически сформированном списке объектов из файла RVT выбираем здание. Далее выбираем этаж, либо группу этажей, для которых необходимо сгенерировать сечение. 

Ставим галочку в пункте *"Прикрепить сечение"*
Нажимаем *“Добавить файл”*.

<image image={step5Image} width="100%" title="Рисунок 73 - 5 шаг создания отчета по инсоляции"/>

Справа появляется панель.

Планы БТИ необходимо выгрузить самостоятельно, с помощью кнопки *“Выбрать файлы”*, либо просто перетащив их в выделенное поле.

Затем нажимаем
*"Загрузить выбранные файлы"*.

Кнопка "Добавить" позволяет вернуться назад и дополнить приложение планами БТИ. 

Кнопка "Прикрепить" формирует список приложений.

Внизу списка приложений кнопка *"Добавить приложение"*.

С её помощью, при необходимости, можно выбрать другое здание из сборки и подгрузить относящиеся к нему сечения, по тому же алгоритму.


### 6 ШАГ

**Графическая часть**

На данном шаге у пользователя есть возможность сгенерировать графический план сцены, который представляет из себя сборку всех зданий на сцене и отображение лучей с информацией о продолжительности инсоляции выбранной расчетной точки. Для этого нужно нажать кнопку "+ Добавить план" (рис. 74).

<image image={step7Image} width="100%" title="Рисунок 74 - Кнопка Добавить план"/>

Данный блок позволяет: (рис. 75)

- выбрать нужную расчетную точку для отображения продолжительности инсоляции;
- настроить позиционирование камеры на здании или на центре сцены при создании листа;
- выбрать необходимый масштаб и формат листа;
- добавить таблицу, содержащую в себе информацию о продолжительности инсоляции расчетной точки.
  

<image image={step77Image} width="100%" title="Рисунок 75 - Настройка графического плана"/>

### 7 ШАГ

**Готово**

Ваш отчёт готов! На этом этапе доступно превью всего отчета, его можно сохранить для редактирования в сервисе. 

<image image={step6Image} width="100%" title="Рисунок 76 - 7 шаг создания отчета по инсоляции"/>

Отчет можно сохранить в PDF. Файл будет скачан и заверен электронной подписью, без дальнейшей возможности редактирования.
