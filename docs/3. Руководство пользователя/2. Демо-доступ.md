Демо-доступ предназначается для пользователей, которые хотят ознакомиться с функционалом и приципами работы сервиса. 
Он характеризуется ограниченным функционалом.


**Условия работы с демо-доступом:**
1.	Отсутствует возможность добавлять свои проекты в сервис;
2.	Расчеты инсоляции, КЕО, площадок проводятся только для демонстрационных моделей;
3.	Функционал проведения расчетов доступен в полном объеме;
4.	Формирование отчетов по инсоляции и КЕО и скачивание их в pdf-формате;

Для того, чтобы получить возможность использования демо-доступа нужно пройти регистрацию или войти в аккаунт по ссылке "bim.insolations.ru"

Доступ по времени не ограничен.
