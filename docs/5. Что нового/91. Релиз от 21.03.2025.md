### Обновления Formit ПД 

1. *Сохранение результатов расчета КЕО*

Теперь, если вы закрыли вкладку/браузер, последние расчеты сохранятся и будут отображаться во вкладке (рис.1).

2. _*Разделение библиотек материалов отделки*_

Ранее была общая библиотека, что могло привести к неверному выбору коэффициента. Мы разделили их для вашего удобства:

Расчет коэффициента отражения фасада (рис.2) и внутреннего отражения помещения (рис.3).

<image image={psrImage} width="100%" title="Рисунок 3 - коэффициент отражения внутренних поверхностей"/>

3. *Расчет угловых окон в инсоляции*

Теперь сервис разбивает семейство окна на светопроёмы, определяет инсоляцию для каждого из окон (рис.4). 
Результатом является сумма инсоляции светопроёмов за исключением общих интервалов.

Например: 
окно 1 инсолируется с 12:00 до 16:00.

Окно 2 инсолируется с 13:40 до 15:20. 

Таким образом, общее время непрерывной инсоляции с 12:00 до 15:20 (3 часа 20 минут).

<image image={yglovieImage} width="100%" title="Рисунок 4 - расчет угловых форм"/>

4. *Улучшилось определение форм в разделе настроек КЕО.*

Теперь при выборе формы на главном экране для вашего удобства подсвечивается форма для назначения средневзвешенного коэффициента отражения фасада (рис.5).
<image image={formImage} width="100%" title="Рисунок 5 - подсвечивание форм"/>

5. *Изменение логики формирования отчета. Переработка формирования расчетных планов.*

При формировании планов расчетных этажей и ситуационных планов будут отображаться только рассчитанные этажи, а также можно будет выбрать сразу несколько этажей для формирования нескольких планов в одно нажатие (рис.6).

### Обновления Formit Концепция

1. *Добавление пользовательских названий для синхронизируемых форм*

В сервисе Концепция можно выбрать параметр для переноса названия форм из Revit в сервис.
Для этого через Экспортер или Новый проект переходите во вкладку "Настройки" (рис.7). 
<image image={nastrImage} width="100%" title="Рисунок 7 - Настройки "/>
Первая вкладка - "Именование форм". Здесь вы выбираете файл, в котором находится параметр, отвечающий за имя формы (рис.8), далее выбираете тот параметр, который используется для названия (рис.9). Нажимаете кнопку "Сохранить". 
<image image={failImage} width="100%" title="Рисунок 8 - Выбираем файл для определения параметра "/>
<image image={parametrImage} width="100%" title="Рисунок 9 - Выбираем сам параметр "/>

2. *Добавление пользовательских параметров для определения площадок*

Вторая вкладка - "Определение площадок" (рис.10). Если в параметре "Группа модели" вы используете любое другое слово, кроме "Площадка", то вам необходимо данное название вписать в поле ввода во вкладке "Определение площадок". Это необходимо для того чтобы сервис мог различить площадки, иначе они экспортируются как обычные перекрытия.
<image image={ploshImage} width="100%" title="Рисунок 10 - Параметр для отображения площадок "/>
