## Обновления Formit ПД
### Экспортер
- Доработана очистка файлов старой версии лаунчера при обновлении;
- Переработана проверка сети и сообщения об отсутствии доступа к серверу;
- Улучшен алгоритм поиска помещений по точкам;
- Улучшен алгоритм поиска и расположения расчётных точек у окон.

*Исправленные ошибки*

- Исправлено положение геометрии в сцене у некоторых составных семейств окон.

### Инсоляция
**Вывод результатов расчета инсоляции**

- Улучшено перемещение по колесу мыши в дереве результатов;
- Добавлены фильтры результатов инсоляции;
- Добавлена сортировка результатов инсоляции.

*Исправленные ошибки*

- Исправление работы с настройками отображения результатов - мгновенный отклик на их изменение.

### КЕО
**Вывод результатов расчета КЕО**

- Добавлены фильтры для вывода результатов;
- Добавлена сортировка для вывода результатов;

### Отчет
**Блок 6 "Приложения" (Нарезка сечений)**

- Добавлена расчетная точка по КЕО при формировании сечения.

*Исправленные ошибки*

- Исправление некорректного формирования отчета по КЕО для нескольких зданий.
