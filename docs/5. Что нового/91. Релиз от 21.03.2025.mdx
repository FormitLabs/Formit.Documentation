## Обновления Formit ПД

### Инсоляция

**Реализация поддержки угловых окон**

Теперь сервис разбивает семейство окна на светопроёмы, определяет инсоляцию для каждого из окон (<ImageLink to="corner-windows"/>).
Результатом является сумма инсоляции светопроёмов за исключением общих интервалов.

Пример:

1. Окно 1 инсолируется с 12:00 до 16:00.
2. Окно 2 инсолируется с 13:40 до 15:20.
3. Общее время непрерывной инсоляции с 12:00 до 15:20 (3 часа 20 минут).

<Image image={yglovieImage} id="corner-windows" width="100%" title="Расчет угловых окон"/>

## Обновления Formit Conception

### Экспортер

**Добавление пользовательских названий для синхронизируемых форм**

В сервисе Концепция реализован выбор параметра для переноса названия форм из Revit в сервис.
Для этого через Экспортер или Новый проект переходите во вкладку "Настройки" (<ImageLink to="settings"/>).
<Image image={nastrImage} id="settings" width="100%" title="Настройки"/>
Первая вкладка - "Именование форм". Здесь вы выбираете файл, в котором находится параметр, отвечающий за имя формы (<ImageLink to="file-select"/>), далее выбираете тот параметр, который используется для названия (<ImageLink to="parameter-select"/>). Нажимаете кнопку "Сохранить".
<Image image={failImage} id="file-select" width="100%" title="Выбираем файл для определения параметра"/>
<Image image={parametrImage} id="parameter-select" width="100%" title="Выбираем сам параметр"/>

**Добавление пользовательских параметров для определения площадок**

Вторая вкладка - "Определение площадок" (<ImageLink to="areas-detection"/>). Если в параметре "Группа модели" вы используете любое другое слово, кроме "Площадка", то вам необходимо данное название вписать в поле ввода во вкладке "Определение площадок". Это необходимо для того чтобы сервис мог различить площадки, иначе они экспортируются как обычные перекрытия.
<Image image={ploshImage} id="areas-detection" width="100%" title="Параметр для отображения площадок "/>
