## Обновления Formit ПД
### Экспортер
- Обновлен установщик экспортера;
- Добавлена возможность использовать стандартные параметры при создании квартирографии;
- Добавлена возможность экспортировать все помещения;
- Удалена фильтрация помещений по использованию.

### Инсоляция площадок
- Исправлена логика учета UTC в алгоритме инсоляции площадок.

### Отчет
**Блок “Расчет инсоляции”**

- Для точки окна добавлен постфикс «(о)», а для номера точки витража «(в)»;
- «Общественные» помещения больше не группируются во вложенность «помещения без квартир»;
- Информация об инсолировании выводится для точек, т.е. для окон и точек витража;
- Для «жилых» помещений добавлен указатель количества комнат.

**Блок “Расчет КЕО”**

- На графических планах исправлен номер точки КЕО;
- Номер точки КЕО не меняется до обновления проекта, т.е. до нового экспорта;
- Осуществляется выведение понижающего коэффициента «К» в отчет, учитывающего наличие балконов и лоджий.
