***

## Обновления Formit ПД

### Экспортер

- Добавлена поддержка proxy;
- Проработаны ошибки при работе c exporter;
- Добавлена возможность "Отправить сообщение об ошибке".

### Инсоляция

- Обновлен дизайн настроек местоположения;
- Увеличена скорость расчета в 3-4 раза;
- Добавлена возможность настроить возврат точки в автоматических настройках.

### КЕО

- Обновлены настройки КЕО;
- Добавлена возможность создавать пользовательскую конфигурацию для τ<sub>1</sub>;
- Добавлена возможность создавать пользовательскую конфигурацию для ρ<sub>ср</sub>;
- Добавлена возможность указывать коэффициент MF;
- Добавлены коэффициенты по умолчанию для: τ<sub>1</sub>, τ<sub>2</sub>, C<sub>N</sub>;
- Добавлена система словарей;
- Добавлена возможность ручной постановки точки КЕО в помещении.

### Отчет

- Переработан отчет по КЕО;
- Уменьшен размер отчета;
- Добавлены инженерные штампы в "Приложения";
- Добавлены инженерные штампы в "Графические планы".

### Сервис

- Добавлена поддержка витражей в просмотре результатов инсоляции по всему зданию.
- Добавлено кеширование моделей. Если проект уже скачан пользователем и не изменялся, то модель будет открыта из кеша.
- Добавлены настройки проекта. В настройках можно указать тип здания/этажа/квартиры/помещения

### Исправленные ошибки

- Лишняя геометрия в сцене при просмотре результатов инсоляции у здания, при частичном расчёте;
- Некорректное формирование отчета по КЕО для нескольких зданий;
- При расчете инсоляции не всегда учитывалось, что здание состоит из нескольких документов;
- Сломанные стили у панели информации о модели в главном меню;
- Артефакты на сцене при отображении пересекающихся прозрачных элементов, при просмотре результатов инсоляции у здания;
- Неправильная обработка результатов расчета при определении прохождения КЕО;
- Исправлены проблемы при расчете инсоляции, когда в сцене больше ~10000 тысяч инсолируемых элементов;
- Учет настроек загрузки модели КЕО;
- Исправлены проблемы отображения сечений в отчете.

## Обновления личного кабинета

- Обновлен дизайн личного кабинета;
- Обновлен дизайн формы регистрации.
