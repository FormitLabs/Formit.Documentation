# Formit.Documentation

Библиотека знаний сервиса `Formit` (ранее `AltecInsolations`), созданная на базе [Docusaurus](https://docusaurus.io/).

## Правила редактирования документации

- Каждая страница документации должна содержать сверху блок с метаданными, где указывается ссылка и другие данные. 
  
  Пример:
    ```Markdown
    ---
    slug: /path/subpath
    ---
    ```
  
- При добавлении информации о новом релизе, нужно указывать в качестве его адреса `/changelog/latest`, и менять ссылку в предыдущем релизе на `/changelog/%date%`, где `%date%` - дата релиза в формате `dd-mm-yyyy`.
- Для добавления картинок нужно использовать компонент `Image`.
